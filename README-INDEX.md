## Bounty Reward Scale

| Bounty scope | Reward |
| --- | ---: |
| Bug fix or small feature | 25 MRG |
| Medium feature | 50 MRG |
| Large feature | 100 MRG |
| Extra-large feature or system-level work | 200 MRG |

Admin ledger payouts use the same scale.
